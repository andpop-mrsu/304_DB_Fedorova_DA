# Лабораторная работа 2. Подготовка скриптов для создания таблиц и добавления данных

## Требования к окружению

Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:

- **Python 3.x** — для запуска утилиты `make_db_init.py`.
  - Windows: проверить командой `python --version` или `py --version`.
  - Linux/macOS: проверить командой `python3 --version`.
- **SQLite 3** — для загрузки SQL-скрипта в базу данных. Проверить командой `sqlite3 --version`.
- **Bash** — для запуска `db_init.bat` (в Windows используется Git Bash, WSL или Cygwin).

## Запуск

```bash
./db_init.bat
```

После выполнения создаётся база данных `movies_rating.db` с заполненными таблицами `movies`, `ratings`, `tags`, `users`.
